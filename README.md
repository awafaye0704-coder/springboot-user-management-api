# User Management API

A modern User Management REST API built with Spring Boot.

## Technologies

* Java 21
* Spring Boot
* Spring Security
* Keycloak
* PostgreSQL
* Liquibase
* Maven
* Swagger / OpenAPI

## Features

* User Management
* Role Management
* Authentication with Keycloak
* Database versioning with Liquibase
* RESTful APIs
* Validation and Exception Handling

## Project Structure

```text
src
 ├── controller
 ├── service
 ├── repository
 ├── entity
 ├── dto
 ├── mapper
 ├── exception
 └── config
```

## Getting Started

```bash
mvn clean install
mvn spring-boot:run
```
